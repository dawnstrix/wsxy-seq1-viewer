# 卫戍协议·规程 序列I 数据查询器

《明日方舟》2026「感谢庆典」常驻赛季 **卫戍协议·规程·序列I**（`act3autochess` / `V3_1`）的可视化查询工具：143 名干员、26 个盟约、61 个策略、70 件装备、16 名领袖与 93 组战术特训敌人，全部离线可用。

**在线试用：** https://dawnstrix.github.io/wsxy-seq1-viewer/

**极简版（单文件 48KB，无图片、双击即用）：** https://dawnstrix.github.io/wsxy-seq1-viewer/lite.html

> 数据抓取时间：2026-11-13。开放期内官方还会做一次内容更新，届时重跑脚本即可刷新。

## 功能

- **分类查询**：等阶 / 核心盟约 / 附加盟约 / 特质词条多选，chip 上实时显示匹配人数
- **干员浮窗**：点头像或名字，看等阶、职业、采购等级、装备栏、升级需求，普通/精锐特质上下等分展示
- **盟约浮窗**：点盟约图标或卡片标题，看效果全文与全部同盟约干员；点干员再进详情，可「返回」盟约
- **分页浏览**：干员 / 盟约 / 策略 / 装备 / 敌人 / 模式
- **三套主题**：协议（默认，深绿军用终端风）/ 深色 / 浅色，右上角循环切换并记住选择
- **深链**：`#tab=bonds`、`#op=初雪`、`#bond=乌萨斯`、`#bondview=谢拉格`、`#theme=light`
- 全离线：`index.html` 内嵌数据，图标走本地 `assets/`，双击即可打开；不想带素材就用 `lite.html`（单文件 48KB）

## 数据来源

| 来源 | 用途 |
| --- | --- |
| `https://torappu.prts.wiki/gamedata/latest/excel/activity_table.json` | 活动主数据：盟约、干员、特质、策略、装备、领袖血量、模式 |
| `.../character_table.json`、`char_patch_table.json` | 干员名称、职业等基础信息 |
| `https://prts.wiki/w/卫戍协议·规程/PRTS盟约记录` | 策略「发起人」、领袖名称（官方 gamedata 里没有名字字段） |

图标来自 PRTS wiki，版权归鹰角网络 / PRTS 贡献者所有，本项目仅作查询展示。

## 目录结构

```
index.html          # 完整版成品（数据内嵌 + 本地图标）
lite.html           # 极简版（单文件、无图片、双击即用）
build_viewer.py     # 由 data/*.csv 重新生成 index.html
build_lite.py       # 由 data/*.csv 重新生成 lite.html
data/*.csv          # 整理后的结构化数据
assets/             # 干员头像、盟约/装备/策略/敌人图标、职业图标
```

## 本地使用 / 重新构建

直接双击 `index.html` 即可，无需服务器。

重新构建：

```bash
python3 build_viewer.py     # 读取 data/*.csv，生成 index.html
```

数据抓取脚本（`fetch_parse.py`、`fetch_images.py`）与 `raw/` 原始缓存未包含在本仓库，重新抓取请参考原始项目说明。

## 统计与已知问题

- 干员 143 名：Ⅰ 19 / Ⅱ 24 / Ⅲ 27 / Ⅳ 27 / Ⅴ 26 / Ⅵ 20（等阶取自 `chessId`）
- 盟约 26 个：核心 10（阵营，3 人激活）、附加 11、特殊附加 5
- 装备 70 件（基础 / 进阶两版），领袖 16 名，战术特训敌人 93 组
- `绝技` 盟约在官方数据里 `chessIdList` 为空，暂时列不出成员
- `协防干员`、`调和`、`独行` 属于特殊规则盟约（`weight=0`），不是常规可选阵营
- 战术特训敌人只有内部 ID，暂无名称与头像
- `boss_12`~`boss_17` 为隐藏领袖，PRTS 领袖表未列出，暂以 ID 占位
- 「盟约之币」「奥术法阵」在图标库里对应旧名「幸运硬币」「口袋法阵」，已做别名映射
